# PCB Silkscreen Image Generator

A lightweight web application that simplifies the creation of **PCB silkscreen labels** by converting tables and images into PCB-ready black-and-white PNG files.

This project was built to eliminate the repetitive and time-consuming process of creating silkscreen images manually from spreadsheet software. Instead of formatting tables in Excel, taking screenshots, cropping, and editing them, this tool generates clean PNG images directly in the browser.

# Features

## 📋 Table to PNG Generator

* Create custom tables with any number of rows and columns.
* Edit text directly inside each cell.
* Automatically generate high-quality PNG images.
* Perfect for PCB connector pinouts, headers, labels, and documentation.

## 🖼 Image to PCB Silkscreen Converter

* Upload any image.
* Convert it into a clean black-and-white version suitable for PCB silkscreen.
* Export the processed image as PNG.

## ⚡ Fast and Simple

* No software installation required.
* Runs entirely in your web browser.
* Instant image generation.

# Why This Project?

While designing PCBs, I frequently needed connector pinout tables on the silkscreen layer.

The traditional workflow looked like this:

Excel → Format Table → Screenshot → Crop → Edit → Convert → Import into KiCad

This process was slow, repetitive, and inefficient.

This application replaces the entire workflow with a few clicks, allowing PCB designers to generate silkscreen-ready PNG images much faster.

# How to Use

## Table Generator

1. Open the application.
2. Specify the desired number of rows and columns.
3. Generate the table.
4. Enter your labels (e.g., VCC, GND, SDA, SCL).
5. Adjust the table if needed.
6. Click **Export PNG**.
7. Import the generated PNG into KiCad or your preferred PCB design software.

---

## Image Converter

1. Open the Image Converter section.
2. Upload an image.
3. Convert it to black and white.
4. Preview the result.
5. Download the PNG.
6. Use it as a PCB silkscreen graphic.
